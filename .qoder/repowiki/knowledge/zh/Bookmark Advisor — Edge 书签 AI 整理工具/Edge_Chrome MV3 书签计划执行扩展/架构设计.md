按 Chrome MV3 三进程模型组织：
- `service_worker.js` 为入口，通过 `importScripts` 顺序加载 `shared/`（协议、Schema、存储）、`background/`（任务编排、书签 API、撤销日志、消息路由）与 `ai/`（提示词编解码、Provider 客户端、Plan Compiler），在 `BookmarkAdvisorSW` 下组装依赖注入式工厂（JobLifecycle → JobHandlers → PlanExecutor → ActionHandlers → BookmarkTree/UndoLog），并通过 `chrome.runtime.onMessage` 暴露给 popup/offscreen。
- `offscreen.html` + `offscreen.js` 是独立渲染进程，仅承担 `fetch` 调用 LLM 以避免 SW 30s idle 限制；通过 `MESSAGE_TYPES.OFFSCREEN_*` 与 SW 双向通信，并在 `bookmarkAdvisorOffscreenResult` storage key 上持久化结果以应对进程重启。
- `ai_planner.js` 作为 OpenAI 兼容 HTTPS 规划 facade，组合 `ai/fast_rules.js`（规则缓存）、`snapshot_model.js`（快照裁剪）、`batching.js`（大目录分片）、`prompt_codec.js` / `response_codec.js`（提示词/响应编解码）、`provider_client.js`（多风格请求重试）、`plan_compiler.js`（激活→可执行计划编译与 lint 自修复）。
- `popup/` 提供 UI 侧状态机、设置与 secrets 管理，通过 `runtime_client.js` 向 SW 发消息。
- 所有模块采用 IIFE + `globalThis.BookmarkAdvisor.*` 挂载，运行时再 `require(...)` 懒加载依赖，形成松耦合装配图。
