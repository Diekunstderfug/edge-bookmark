本模块为纯资源型叶子目录，按用途分为四层：
- `tests/`：双轨测试集。Python CLI 逻辑使用 stdlib `unittest.TestCase`（由 `AGENTS.md` 约定），通过 `PYTHONPATH=src python3 -m unittest discover -s tests` 运行；Edge 扩展相关用例使用 pytest 启动 Node.js 子进程并注入 mock `chrome` 全局，覆盖 service worker、popup、plan lint、endpoint URL、prompt/规则/URL parity 等。
- `skills/`：面向 AI agent 的可执行工作流说明，`bookmark-reorg/SKILL.md` 定义 snapshot→review→enrich→plan→finalize→apply 六阶段流水线，并通过 frontmatter `name`/`description` 被上层编排器识别；`bookmark-url-review` 作为独立子技能提供 URL 语义审查。
- `config/rules.yaml`：用户级书签整理策略声明文件，包含 `defaults`、`category_hints`、`folder_relocations`、`bookmark_relocations`、`protected_paths` 五个段，供运行时加载。
- `docs/`：静态设计文档，含 `design/DESIGN.md`、`superpowers/plans` 与 `specs` 下的时间戳命名计划/规范，以及若干一次性审计报告（code-quality、maintainability、multi-agent、test_flakiness）。
依赖方向单向向外：测试仅依赖 `src/` 中的实现，不反向引入业务代码；skills 与 docs 不被任何源码引用。
