- 测试文件统一以 `test_*.py` 命名，Python CLI 用例继承 `unittest.TestCase` 并使用 `self.assert*`，禁止在测试中混用 pytest 断言。
- 每个测试方法使用 `tempfile.TemporaryDirectory()` 创建隔离临时目录，避免跨用例共享状态。
- Extension 测试通过内联 JS 字符串构造 mock `chrome` API 调用（如 `bookmarkCall("get", ...)`），而非外部 fixture。
- Skills 与 plans/specs 采用 ISO 日期前缀的文件名（如 `2026-05-17-his-emr-source-separation.md`）保证可排序与可追溯。
- SKILL.md 使用 YAML frontmatter 声明 `name`/`description`，并在正文中以 Markdown 标题划分 phase rules、entry point 等结构化章节。
