顶层由两个互补子模块组成：`extension/`（Edge MV3 Service Worker + Offscreen Document）负责在浏览器内读取 `chrome.bookmarks`、调用 OpenAI 兼容 API 生成并审阅操作计划、按策略引擎逐项执行并提供撤销；`src/bookmark_advisor/`（setuptools src-layout Python 包，入口 `bookmark-advisor`）提供快照导出、URL 审查队列、富化快照、离线 AI 规划与多阶段 job runner。两者通过共享的 JSON 工件目录 `data/`（snapshots/plans/jobs/reports）以及 `config/rules.yaml` 规则文件协作：CLI 可导出/富化快照供扩展消费，扩展也可导出快照供 CLI 离线处理；job runner 顺序编排 export → review-queue → enrich → ai-plan → finalize，并以文件锁和 extension waiting phase 协调两端。`tests_and_docs/` 聚合两者的 unittest/pytest 用例与技能说明文档。
