### Bookmark Advisor
- 定义：项目主产品名称，指代整个 AI 驱动的 Edge 书签整理工具套件，包含浏览器扩展和 Python CLI 两部分。
- 别名：bookmark-advisor、书签顾问

### 快照 (Snapshot)
- 定义：从 Edge 书签文件导出的结构化 JSON 数据，包含完整的书签树结构、文件夹信息和元数据，是所有后续处理的输入基础。
- 别名：snapshot.json、书签快照

### 富化快照 (Enriched Snapshot)
- 定义：在原始快照基础上合并 URL 审核结果后的增强版快照，包含每个公开 URL 的语义信息（如页面标题、描述、内容类型等），用于更准确的 AI 规划。
- 别名：enriched-snapshot.json、富化快照

### 审核队列 (Review Queue)
- 定义：从快照中提取的待审核书签列表，专门针对公开 URL 的书签，用于人工或自动化审核流程。
- 别名：review-queue.json、审核队列

### URL 审核 (URL Review)
- 定义：对公开书签 URL 进行语义分析的过程，确定网站实际用途并生成审核结果侧车文件，是 AI 规划前的必要步骤。
- 别名：url-review.json、URL审核

### 草稿方案 (Draft Plan)
- 定义：由 AI 生成的初步书签整理建议，包含移动、创建文件夹等操作提议，状态为 'proposed'，需要进一步审核。
- 别名：draft-plan.json、草稿方案

### 已审核方案 (Reviewed Plan)
- 定义：经过人工或自动审核后的最终可执行方案，只包含状态为 'approved' 或 'edited' 的操作，可直接用于执行。
- 别名：reviewed-plan.json、已审核方案

### 作业 (Reorg Job)
- 定义：编排完整书签重组工作流的运行时状态文件，跟踪从导出到执行的各个阶段，支持断点续跑。
- 别名：reorg-job.json、重组作业

### 保护根路径 (Protected Paths)
- 定义：在 rules.yaml 中配置的受保护根文件夹路径（如 /收藏夹栏、/其他收藏夹），这些路径下的散落书签默认不会被自动移动。
- 别名：protected_paths、保护路径

### 强制重定位 (Forced Relocation)
- 定义：rules.yaml 中定义的硬性规则，指定特定书签或文件夹必须移动到目标位置，优先级高于 AI 建议。
- 别名：forced_relocation、强制规则

### 隔离区 (Quarantine)
- 定义：特殊文件夹 `_Quarantine`，用于存放重复书签而非永久删除，提供安全的数据恢复机制。
- 别名：quarantine、隔离区

### 执行策略 (Execution Policy)
- 定义：控制计划执行的安全策略引擎，包括聚焦范围检查、路径验证、操作许可等安全护栏。
- 别名：policy engine、执行策略

### 撤销日志 (Undo Log)
- 定义：记录每次执行操作的预状态（parentId/title），支持一键撤销最近一次执行批次的功能。
- 别名：undo log、撤销日志

### 分类提示 (Category Hints)
- 定义：rules.yaml 中定义的主题关键词映射，帮助 AI 将书签归类到合适的现有文件夹，如 ai、machinelearning、编程等类别。
- 别名：category_hints、分类提示

### 散书签 (Loose Bookmarks)
- 定义：直接挂在根文件夹（如收藏夹栏、其他收藏夹）下的一级书签，通常缺乏明确的分类上下文。
- 别名：loose bookmarks、散落书签

### 保持审核 (Keep for Review)
- 定义：一种特殊的操作类型，表示该书签暂时无法自动分类，需要人工介入决策，置信度较低。
- 别名：keep_for_review、待审核
